# Сайт Академії Viatec

Статичний сайт з адмінкою. Без бази даних і серверного коду: працює на
будь-якому хостингу або безкоштовно на Cloudflare Pages, зламати нічого, кожна правка зберігається в історії й може бути відкочена.

## Що де лежить

| Папка / файл | Що це | Хто редагує |
|---|---|---|
| `content/*.json` | Усі дані: курси, розклад, лабораторії, відео, фото, відгуки, FAQ, контакти, тексти | **Адмінка** |
| `img/uploads/` | Фото, завантажені через адмінку (автоматично стискаються в WebP) | **Адмінка** |
| `admin/` | Сама адмінка (`config.yml` — які поля в ній є) | Розробник |
| `index.html` | Головна сторінка | Розробник |
| `course.html` | Шаблон сторінки курсу (`course.html?id=cctv`) | Розробник |
| `js/quiz.js` | Питання й бали квізу «Підібрати курс» | Розробник |
| `css/style.css` | Дизайн. Кольори — на початку файлу в `:root` | Розробник |
| `apps-script/Code.gs` | Обробник заявок для Google Таблиці | Один раз при налаштуванні |
| `Open-site-Windows.bat`, `Open-site-Mac.command`, `tools/` | Перегляд сайту на своєму комп'ютері | — |
| `.github/workflows/deploy-ftp.yml` | Автозаливка на звичайний хостинг | Один раз при налаштуванні |

## 1. Перегляд і редагування на своєму комп'ютері

**Подивитись сайт:** у папці сайту двічі клацніть
**`Open-site-Windows.bat`** (на Mac — `Open-site-Mac.command`).
Відкриється чорне вікно й браузер із сайтом. Вікно не закривайте, поки дивитесь;
закрили — сайт зупинився. Подвійний клік по `index.html` не працює: браузер
не дає сторінці читати файли з диска.

> Windows може показати «Windows захистила ваш ПК» — натисніть
> *Детальніше → Виконати в будь-якому разі*. Файл нічого не встановлює.

**Адмінка на комп'ютері (без інтернет-акаунтів):**
1. Запустіть сайт, як вище, відкрийте в **Chrome або Edge** адресу з чорного вікна, додавши `/admin/`
   (зазвичай `http://localhost:8080/admin/`).
2. Натисніть **Work with Local Repository** і виберіть **папку сайту** (ту, де лежить `index.html`).
3. Редагуйте. Зміни записуються прямо у файли в папці. Оновіть вкладку із сайтом, щоб побачити їх.

Для адмінки потрібен інтернет (вона завантажується з unpkg.com), а папка має
містити приховану підпапку `.git` — вона вже є в архіві, не видаляйте її.

## 2. Публікація в інтернеті

Є два шляхи. Адмінка однакова в обох: вона зберігає зміни в репозиторії
на GitHub, а звідти сайт автоматично оновлюється.

### Спільне для обох: GitHub (≈10 хв)

1. Заведіть акаунт на github.com на пошту Академії.
2. Встановіть **GitHub Desktop** (desktop.github.com) і увійдіть.
3. *File → Add local repository* → виберіть папку сайту.
4. **Publish repository** → залиште галочку **Keep this code private** → Publish.
5. На github.com відкрийте `admin/config.yml` → олівець ✏️ → замініть
   `ВЛАСНИК/РЕПОЗИТОРІЙ` на свій (напр. `academy-viatec/academy-site`) → *Commit changes*.
6. У GitHub Desktop натисніть **Fetch origin → Pull**, щоб ця правка була й у вас.

> Правили сайт локально через адмінку? У GitHub Desktop: опишіть зміну внизу
> ліворуч → **Commit to main** → **Push origin**. Сайт в інтернеті оновиться.

### Шлях А (рекомендований): Cloudflare Pages, безкоштовно

Хостинг купувати не треба, лише домен.
1. cloudflare.com → *Workers & Pages → Create → Pages → Connect to Git* → репозиторій сайту.
2. *Framework preset* — **None**, *Build command* — **порожньо**, *Build output directory* — **/** → *Deploy*.
3. Через хвилину сайт на `назва.pages.dev`. Свій домен: *Custom domains → Set up a custom domain*.

### Шлях Б: Заливка на куплений хостинг

Підійде будь-який хостинг з FTP (cPanel, ISPmanager тощо). Підтримка PHP чи
бази даних не потрібна. Заливку робить GitHub автоматично після кожної зміни.
1. У панелі хостингу знайдіть дані FTP: сервер, логін, пароль і папку сайту
   (зазвичай `public_html/` або `www/назва-домену/`).
2. github.com → репозиторій → *Settings → Secrets and variables → Actions*:
   - вкладка **Secrets** → *New repository secret*: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`;
   - вкладка **Variables** (якщо папка не `public_html/`): `FTP_DIR`, напр. `www/academy.com.ua/`
     (зі слешем у кінці). Якщо хостинг не підтримує FTPS — додайте `FTP_PROTOCOL` = `ftp`.
3. Вкладка **Actions** → «Заливка на хостинг» → *Run workflow*. Через 1–2 хв сайт на хостингу.
4. Далі кожна зміна з адмінки заливається сама.

Файл `.htaccess` уже налаштований для типового хостингу на Apache.
Сайт має лежати в **корені домену** (не в підпапці), інакше фото з адмінки не відкриватимуться.

### Після публікації (обидва шляхи)

У `index.html` замініть `[ВАШ-ДОМЕН]` на свій домен (canonical, og:image).

## Вхід в адмінку в інтернеті

Адреса: `https://ваш-домен/admin/`

**Найпростіше (працює одразу):** кнопка **Sign In Using Access Token**.
1. GitHub → *Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token*.
2. *Repository access* — лише репозиторій сайту.
   *Permissions → Contents* — **Read and write**.
3. Скопіюйте токен і вставте в адмінці. Браузер його запам'ятає.

Кожному, хто редагує сайт (менеджеру), — свій акаунт GitHub, доступ до
репозиторію (*Settings → Collaborators*) і свій токен.

**Зручніше (кнопка «Sign In with GitHub»):** розгорніть безкоштовний
[Sveltia CMS Authenticator](https://github.com/sveltia/sveltia-cms-auth) на
Cloudflare Workers за його інструкцією, потім у `admin/config.yml`
розкоментуйте `base_url` і вставте адресу воркера.

## 3. Форми заявок → Google Таблиця + Telegram

1. Створіть Google Таблицю «Заявки Академії».
2. *Розширення → Apps Script*, видаліть усе в редакторі, вставте вміст `apps-script/Code.gs`.
3. **Telegram (за бажанням):** у Telegram напишіть @BotFather → `/newbot` → отримаєте токен.
   Додайте бота в робочу групу, напишіть у групу будь-що, відкрийте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайдіть `"chat":{"id":-100…}`.
   Впишіть токен і id у `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`. Або вкажіть `NOTIFY_EMAIL`.
4. Збережіть, виберіть функцію `testPost` → *Виконати* → дозвольте доступ.
   У таблиці з'явиться аркуш і тестовий рядок, у Telegram — повідомлення.
5. *Розгорнути → Нове розгортання → Тип: Веб-застосунок*.
   *Виконувати як* — **Я**, *Доступ* — **Усі**. Скопіюйте адресу `https://script.google.com/macros/s/…/exec`.
6. В адмінці: *Налаштування сайту → Адреса обробника форм* — вставте цю адресу, опублікуйте.

Заявки розкладаються по аркушах: курси, корпоративні, робосумо. Колонка
«Статус» має випадний список: Нова → Передзвонили → Записаний → Оплатив.

> Якщо змінюєте `Code.gs`, робіть *Розгорнути → Керувати розгортаннями → ✏️ → Нова версія*,
> інакше працюватиме стара версія.

## 4. Як додавати контент

- **Нова група в розклад:** Адмінка → Курси й розклад → Розклад груп → «Додати групу».
  Минулі групи зникають із сайту самі. Коли місця закінчились — поставте «Вільних місць: 0».
- **Новий курс:** Курси й розклад → Сертифікаційні курси → «Додати курс».
  Його сторінка з'явиться автоматично: `course.html?id=<код>`.
- **Лабораторія на карті:** Лабораторії → «Додати лабораторію». Координати —
  у Google Maps правий клік по місцю, перше число широта, друге довгота.
- **Фото:** будь-які, навіть 8 МБ з телефона: адмінка сама зменшить і стисне.
- **Відео:** лише через YouTube (можна «Доступ за посиланням»), в адмінку — посилання.
  Не завантажуйте відеофайли на сайт.

## 5. Аналітика

Вставте код Google Analytics 4 та/або Meta Pixel перед `</body>` в `index.html`
і `course.html`. Сайт сам надсилає події: `generate_lead` / `Lead` (заявка)
і `quiz_complete` (квіз). Посилання з реклами додавайте з UTM-мітками —
вони потраплять у таблицю заявок.
